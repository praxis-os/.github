# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in any Praxis OS repository, please report it privately. **Do not open a public GitHub issue.**

Send your report to: **security@praxis-os.dev**

> This address may be updated as the project grows. If it bounces, use the contact information on the [organization profile](https://github.com/praxis-os) or reach out to a maintainer directly.

Include in your report:

- Description of the vulnerability
- Steps to reproduce or a proof of concept
- Affected component and version (or commit hash)
- Potential impact assessment, if known

## What to expect

- We will acknowledge receipt within a reasonable timeframe. We do not commit to a specific SLA at this stage, but we take security reports seriously.
- We will work with you to understand and validate the issue.
- We will coordinate disclosure timing with you where appropriate.
- We will credit reporters in release notes unless they prefer otherwise.

## Supported versions

Praxis OS is pre-v1.0. Security support currently applies to the latest commit on the `main` branch of each public repository. There are no long-term support branches at this time.

## Scope

This policy covers all repositories under the `praxis-os` GitHub organization. If you are unsure whether an issue qualifies as a security vulnerability, err on the side of reporting it privately.
